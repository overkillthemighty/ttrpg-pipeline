Welcome

This site turns a recording of a tabletop game session into a written transcript that says who said what. You give it audio; it gives back a transcript and one cleaned-up recording of the session.

1. What it does

  1. Audio in. Ideally one microphone per person (clip-on lav mics), or a single mic in the middle of the table.
  2. Line up. Separate mics start recording at slightly different moments. Everyone claps once at the start; the server finds that clap on every track and lines them up.
  3. Clean up and mix. The tracks are levelled and mixed into one recording of the whole session.
  4. Transcribe. Speech recognition (Whisper) writes down every word with a timestamp.
  5. Who said it. For each word, the server checks which mic heard it loudest (allowing for each voice bleeding into the other mics) and labels the line with that player's name.
  6. Deliver. The transcript and mix are saved on the job page{% if nextcloud_enabled %} and, if your account publishes to Nextcloud, copied to the campaign folder{% endif %}.

Everything heavy runs on the server. Your computer only records and uploads. A session takes anywhere from a few minutes to about as long as the session itself, depending on the server's hardware.

2. Two ways to mic the table

Lav mics (recommended)

Each player and the DM wears a clip-on mic. Wireless lav receivers are usually stereo, so one receiver carries two people (left and right channel).

  • Lines are labelled with real player names.
  • Most accurate. Lines get a single speaker about 90% of the time; when two people talk at once you'll see A+B.
  • Needs a clap at the start of each recording so the tracks can be lined up.

Room mic only (best effort)

One microphone records the whole table. Use it when the lavs aren't available.

  • No clap needed.
  • No player names. Without speaker guessing you get timestamped lines with no speaker.
  • {% if diarize_available %}With Guess speakers on, lines are labelled Speaker 1, Speaker 2, ... These are guesses: they can split or merge people, and they aren't matched to players.{% else %}Speaker guessing isn't set up on this server, so lines have no speaker.{% endif %}

A. Record in the browser

  1. Open Record in Chrome or Edge, using the site's https:// address (browsers only allow microphones on secure pages).
  2. Close Teams, Discord or anything else that might be holding the receivers.
  3. Click Allow microphones, then choose Lav receivers or Room mic only.
  4. For lavs, pick each receiver and type a player name for each channel (no spaces). Watch the level meters move as each person talks. Tick not used for an empty channel.
  5. Click Start recording, then have everyone clap once, loudly.
  6. Keep the tab open for the whole session. Audio uploads in the background as you go.
  7. Click Stop at the end. The server builds the tracks and opens the new job.

B. Laptop scripts (Windows)

  1. On Laptop scripts, click Download with a new API key. The zip contains the scripts and a config.json already pointed at this server.
  2. Right-click the zip, Properties, tick Unblock, then extract it next to ffmpeg.exe and ffprobe.exe.
  3. Set playerCount in config.json (players plus the DM).
  4. Run .\record.ps1 in PowerShell. Choose devices the first time, check levels, then clap once.
  5. Press Q to stop, then Y to sync and upload. It shows progress until the transcript is ready; closing the window doesn't stop the server job.

Room mic only: .\record.ps1 -Single. The full list of options is in the project README.

C. Upload files

  1. Open Upload and choose what kind of audio you have:
    • Raw player recordings: one file per player, straight off the recorder. The server finds the clap and lines them up.
    • Already synced: the synced_*.flac files the laptop scripts produce.
    • Room mic only: a single recording of the whole table.
  2. Check the Speaker label next to each file (it defaults to Player1, Player2, ...). That label is the name shown in the transcript. Don't include a room mic in a lav upload.
  3. Set the session date (results are filed by the date you played, not the upload date) and submit.

No clap on your raw files? Set Clap to ignore it and the tracks are used as recorded, or type the clap times yourself if you can find them in an audio editor.

4. After you submit

Every recording or upload becomes a job on the Jobs page. The server works on one job at a time, so yours may wait in line.

uploadingAudio is still arriving.
queuedWaiting for another job to finish.
runningBeing lined up, transcribed and labelled. The bar shows the current step.
reviewThe claps didn't line up and you asked to be consulted. Open the job and choose how to sync it.
doneFinished. Results are on the job page.
failedSomething went wrong. The job page shows the error; Retry picks up from the last finished step.
cancelledStopped by someone. It can be retried.

You can close the browser or laptop while a job runs. Everyone can see the queue, but only you (and people allowed to see all outputs) can open your transcript.

5. What you get back

  • transcript_lav_assigned.md: the readable transcript, one line per utterance with time and speaker.
  • transcript_lav_assigned.csv: the same, for a spreadsheet.
  • transcript_lav_assigned.json: the same with word-level detail, for other tools.
  • lav_mix.flac: one mixed recording of the whole session (the room recording, for room-mic sessions).

Download them from the job page.{% if nextcloud_enabled %} If your account is set to publish to Nextcloud, they are also placed in the campaign's Nextcloud folder, named by session date.{% endif %} The server keeps only these four files after a successful job; the original recordings stay on the computer that made them.

6. Tips and common problems

  • Clap once, loudly, right after starting. Clap again whenever a recording restarts (the page or script beeps and tells you).
  • Check the meters before you start. Each person should move only their own meter. If both channels of a receiver always move together, a browser extension (voice changer, noise canceller, meeting recorder) is intercepting the mic. Turn it off for this site and reload.
  • A receiver dropped out? Recording restarts automatically as a new part once it's back. Clap again. The gap becomes silence and everyone stays in sync.
  • Browser or laptop closed mid-session? Nothing recorded so far is lost. Reopen Record (or run record.ps1 again) and choose to resume or finish.
  • Transcript labels look wrong? Usually a mic was swapped between players or a name was typed on the wrong channel. Check the job's log, which lists which device and channel each name came from.
  • Forgot your password? There's no reset email. Ask the server admin to reset it.
