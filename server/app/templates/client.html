Installing

  1. Right-click the zip, choose Properties, tick Unblock, then extract. Otherwise PowerShell may refuse to run the scripts (fix afterwards with Get-ChildItem *.ps1 | Unblock-File).
  2. Extract next to ffmpeg.exe and ffprobe.exe (they aren't included).
  3. Run .\record.ps1.
