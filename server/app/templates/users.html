Users

Add user

  • Admin: manages users, sees and manages every job and every API key. Includes See all outputs.
  • See all outputs: can open other people's transcripts, downloads and logs. Without it a user still sees every job and its progress in the queue, but only their own jobs' output, and can only cancel, retry or delete their own.
  • Publish to Nextcloud: on, the user's results are uploaded to the campaign folders in Nextcloud; off, they stay on this server and the user downloads them from each job page.

Permissions also apply to the API keys a user creates (the laptop scripts). New users start with all three off.
